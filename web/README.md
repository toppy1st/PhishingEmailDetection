# Web Interface

This folder will contain the user interface for our Phishing Email Detection system.

## Planned Features

- A text area for entering email content.
- A button to analyze the email.
- Display the classification result as phishing or legitimate.
- A simple and user-friendly design.
- Integration with the Java backend.

## Technologies

- HTML
- CSS
- JavaScript
- Java (Backend)

## Development Status

This is just the extra plan that we have and it will be started only after the core algorithm and dataset evaluation are completed.
